# Pong Game

## Overview

My fifth Raylib project featuring a very basic recreation of the classic pong game. Some speed or movement values might need some tuning to perfect it though.

## Technologies Used

- C#
- Raylib

## How It Works

Move your paddle up and down to hit the ball by predicting its trajectory. Avoid the ball hitting your side of the screen (Left Side) and aim to score by letting the ball touch the right side of the screen.

## Controls

| Key | Action |

| W | Move Up |

| S | Move Down |

## What I Learned

- Basic AI for oponent paddle
- Ball physics when bouncing
