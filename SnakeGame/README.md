# Snake Game

## Overview

My fourth Raylib project featuring the nostalgic snake game. Not a perfect recreation of the snake game as this is still part of a learning adventure.

## Technologies Used

- C#
- Raylib

## How It Works

Move around the map and collect as many apples (Red squares) as possible to increase your length. Avoid the edges of the grid and your own body as colliding with it will trigger an end game state.

## Controls

| Key | Actions |

| W | Move Up |

| A | Move Left |

| S | Move Down |

| D | Move Right |

## What I Learned

- Grid like movement
- Movement on a timer
- Basic Collision / Overlapping
- Random Food spawning locations
- Score tracking
