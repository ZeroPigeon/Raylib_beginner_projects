# Particle Simulation

## Overview

My seventh Raylib project featuring a crude particle simulation. Simulate snow, rain and fire with mesmerizing effects using particles.

## Technologies Used

- C#
- Raylib

## How It Works

Spawn multiple particles with specific rules that tell the particle how to act based on the state of the simulation.

## Controls

| Key | Action |

| S | Snow Simulation |

| R | Rain Simulation |

| Space (Only for rain simulation) | Change wind direction of rain |

| F | Fire Simulation |

## What I Learned

- Particle Life times
- Multi-object rules for emergance
- Separated classes for each particle
