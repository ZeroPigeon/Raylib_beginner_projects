# Breakout Game

## Overview

My sixth Raylib project featuring the breakout game with some changes to make it a bit easier on myself

## Technologies Used

- C#
- Raylib

## How It Works

Move the paddle side to side and bounce the ball to hit different blocks and destroy them to increase your score. Destroy all the blocks and avoid letting the ball touch the ground to win.

## Controls

| Key | Action |

| A | Move Left |

| D | Move Right |

## What I Learned

- Collision detection between the ball and blocks
- Arrays for specific classes
- Win/Lose State
